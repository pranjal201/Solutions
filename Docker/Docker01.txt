Docker helps with containerization of the apps.
 
it has 3 parts:
    >CLI
    >Engine
    >Registry (docker hub)


Docker file Format
:: FROM > tells about the base image to choose
:: WORKDIR > the code base location
:: COPY > . .
:: RUN > to list the commands to run pip install -r requirements.txt
:: EXPOSE > THE port to expose
:: CMD > the command to execute ["python","manage.py","runserver","0.0.0.0:8000"]
