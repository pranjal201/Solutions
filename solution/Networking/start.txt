## Client Server Architecture
* made a lot of stuff easier
* Separate the application in to two separate components 
* Client calls server to perform expensive tasks
* gave birth to the RPC (Remote Procedural Call)


We needed a Communication Model to effectively transfer data
Why???
 *Agnostic Application [ to create apps that work on various platforms]
     ** If there was not such standard model to adhere to, the app must have knowledge of the underlying network medium that it is working on.
    ** If you used Radio waves, Optical Fiber cables , all needed a different setup.
 *Network Equiment management, as standard model , helps them communicate.



Hence came OSI => Open System Interconnection Model
