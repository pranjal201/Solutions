## Commands related to HTOP for system process monitoring

> ### shift+e 
 converts the memory into different format, MB,KB,GB,PB for display.


> ### Press 1
this shows all the CPU, and what is the wait or nice value ( this are a unix values , which are used by the os to priorities the execution of the processes on the server


> ### Shift + H
 
 how many threads are generated by a particular process // basically a toggle

> ### d + time
helps to set up the refresh durations of the top command need to provide time values

> ### u + username
help to filter out the process by the user, need toprovide username
