## Commands related to HTOP for system process monitoring

[shift+e] => converts the memory into different format, MB,KB,GB,PB for display.


[ Press 1  ] => this shows all the CPU, and what is the wait or nice value ( this are a unix values , which are used by the os to priorities the execution of the processes on the server


[Shift + H] => how many threads are generated by a particular process // basically a toggle

[d + time] => helps to set up the refresh durations of the top command need to provide time values


[u + username] => help to filter out the process by the user, need toprovide username

-e
 •   Meaning: Select all processes.
 •   Explanation: This option ensures that processes for all users, including system processes, are displayed.

-a
 •   Meaning: Show processes for all users except session leaders (e.g., login shells) and processes without a terminal.
 •   Explanation: It includes processes not associated with the current terminal but excludes very low-level processes.

-f
 •   Meaning: Full-format listing.
 •   Explanation: Provides additional information about each process, including parent process IDs and start times.
